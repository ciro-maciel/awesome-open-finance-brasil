It starts with the Central Bank and governance, moves through the official specifications and ends with the community's open source code. Every address was opened before being listed.

## Regulations and governance

Who regulates and where the rules are.

- [Open Finance no Banco Central](https://go.mymarketing.click/ofbr-open-finance-no-banco-central) - The Banco Central page with the regulation, the phases and the frequently asked questions. `official` `free`
- [Open Finance Brasil](https://go.mymarketing.click/ofbr-open-finance-brasil) - The portal for the governance structure, for citizens and participants. `official` `free`
- [Open Insurance na Susep](https://go.mymarketing.click/ofbr-open-insurance-na-susep) - The open insurance system, regulated by Susep. `official` `free`
- [Open Insurance Brasil](https://go.mymarketing.click/ofbr-open-insurance-brasil) - The portal for the Open Insurance structure. `official` `free`

## Specifications and developer area

What a participant implements.

- [Área do desenvolvedor](https://go.mymarketing.click/ofbr-area-do-desenvolvedor) - The API specifications, security and user experience specifications. `official` `free` `API`
- [OpenAPI do Open Finance](https://go.mymarketing.click/ofbr-openapi-do-open-finance) - The official OpenAPI files for the APIs. `official` `free` `open source`
- [Especificações de segurança](https://go.mymarketing.click/ofbr-especificacoes-de-seguranca) - The FAPI security profiles and the use of certificates in the ecosystem. `official` `free` `open source`
- [Especificações do diretório](https://go.mymarketing.click/ofbr-especificacoes-do-diretorio) - How the central participant directory works. `official` `free` `open source`
- [Mock API](https://go.mymarketing.click/ofbr-mock-api) - Docker image with sample API responses, for testing without a bank. `official` `free` `open source`
- [Massa de dados](https://go.mymarketing.click/ofbr-massa-de-dados) - Test data for the APIs. `official` `free` `open source`
- [Aplicações de exemplo](https://go.mymarketing.click/ofbr-aplicacoes-de-exemplo) - Example applications that consume the APIs. `official` `free` `open source`

## Open data from the ecosystem

What anyone can query.

- [Participantes](https://go.mymarketing.click/ofbr-participantes) - The public list of participating institutions, in JSON. `official` `free` `API`
- [Painel do Open Finance](https://go.mymarketing.click/ofbr-painel-do-open-finance) - The ecosystem numbers: API calls, consents and availability. `official` `free`

## Aggregators and initiators

Who connects accounts for you. In alphabetical order.

- [Belvo](https://go.mymarketing.click/ofbr-belvo) - Financial data and payments API via Open Finance. `API` `paid`
- [Iniciador](https://go.mymarketing.click/ofbr-iniciador) - Payment initiation via Open Finance. `API` `paid`
- [Klavi](https://go.mymarketing.click/ofbr-klavi) - Open Finance data for credit and risk analysis. `API` `paid`
- [Pluggy](https://go.mymarketing.click/ofbr-pluggy) - API to connect accounts and read transactions via Open Finance. `API` `paid`

## Open source

References, clients and MCP servers built by the community.

- [Meu Pluggy](https://go.mymarketing.click/ofbr-meu-pluggy) - Application to connect your own account to Open Finance and export your data. `open source` `free`
- [pix-automatico-reference](https://go.mymarketing.click/ofbr-pix-automatico-reference) - Reference implementation of Pix Automático with the consent flow. `open source` `free`
- [open-finance-payments-reference](https://go.mymarketing.click/ofbr-open-finance-payments-reference) - Reference implementation in Java of a payment initiator. `open source` `free`
- [regulatorio-bcb-fundamentos](https://go.mymarketing.click/ofbr-regulatorio-bcb-fundamentos) - Introductory technical guide to Pix, DICT, Open Finance and Susep. `open source` `free`
- [pluggy-mcp-server](https://go.mymarketing.click/ofbr-pluggy-mcp-server) - Read-only MCP server for personal financial data via Pluggy. `open source` `free`
- [banco-mcp](https://go.mymarketing.click/ofbr-banco-mcp) - Open Finance MCP server for Claude and Cursor. `open source` `free`
- [logos-bancos-br](https://go.mymarketing.click/ofbr-logos-bancos-br) - Logos of Brazilian banks, fintechs and cooperatives in PNG and SVG, by COMPE code. `open source` `free`

## Tags

Each item says what it is. The tags next to it help you choose: official when it comes from whoever sets the standard, open source when the code is published, free or paid by usage model, API and SDK by how you integrate. Items tagged "by the author" are made by Ciro Cesar Maciel and follow the same rules as all the others.

Know something that's missing, changed, or went offline? Open an issue with the new entry form or send a pull request editing data/list.json. Each language's README is generated from that file.
