## Normas y gobernanza

Quién regula y dónde están las reglas.

- [Open Finance no Banco Central](https://go.mymarketing.click/ofbr-open-finance-no-banco-central) - La página del Banco Central con la regulación, las fases y las preguntas frecuentes. `oficial` `gratis`
- [Open Finance Brasil](https://go.mymarketing.click/ofbr-open-finance-brasil) - El portal de la estructura de gobernanza, para ciudadanos y participantes. `oficial` `gratis`
- [Open Insurance na Susep](https://go.mymarketing.click/ofbr-open-insurance-na-susep) - El sistema de seguros abierto, regulado por la Susep. `oficial` `gratis`
- [Open Insurance Brasil](https://go.mymarketing.click/ofbr-open-insurance-brasil) - El portal de la estructura de Open Insurance. `oficial` `gratis`

## Especificaciones y área de desarrollador

Lo que implementa un participante.

- [Área do desenvolvedor](https://go.mymarketing.click/ofbr-area-do-desenvolvedor) - Las especificaciones de las APIs, de seguridad y de experiencia de usuario. `oficial` `gratis` `API`
- [OpenAPI do Open Finance](https://go.mymarketing.click/ofbr-openapi-do-open-finance) - Los archivos OpenAPI oficiales de las APIs. `oficial` `gratis` `código abierto`

- [Especificações do diretório](https://go.mymarketing.click/ofbr-especificacoes-do-diretorio) - Cómo funciona el directorio central de participantes. `oficial` `gratis` `código abierto`
- [Mock API](https://go.mymarketing.click/ofbr-mock-api) - Imagen Docker con respuestas de ejemplo de las APIs, para probar sin un banco. `oficial` `gratis` `código abierto`
- [Massa de dados](https://go.mymarketing.click/ofbr-massa-de-dados) - Datos de prueba para las APIs. `oficial` `gratis` `código abierto`
- [Aplicações de exemplo](https://go.mymarketing.click/ofbr-aplicacoes-de-exemplo) - Ejemplos de aplicaciones que consumen las APIs. `oficial` `gratis` `código abierto`

## Agregadores e iniciadores

Quién conecta las cuentas por ti. En orden alfabético.

- [Belvo](https://go.mymarketing.click/ofbr-belvo) - API de datos financieros y pagos vía Open Finance. `API` `de pago`
- [Iniciador](https://go.mymarketing.click/ofbr-iniciador) - Iniciación de pagos por Open Finance. `API` `de pago`
- [Klavi](https://go.mymarketing.click/ofbr-klavi) - Datos de Open Finance para crédito y análisis de riesgo. `API` `de pago`
- [Pluggy](https://go.mymarketing.click/ofbr-pluggy) - API para conectar cuentas y leer transacciones vía Open Finance. `API` `de pago`

## Etiquetas

Cada elemento dice qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los elementos con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
