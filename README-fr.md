Pour ceux qui doivent lire les données d'un compte ou initier un paiement via Open Finance, en tant que participant ou client d'un agrégateur. On commence par la Banque centrale et la gouvernance, on passe par les spécifications officielles et on finit par le code ouvert de la communauté. Chaque adresse a été vérifiée avant d'être ajoutée.

## Normes et gouvernance

Qui régule et où se trouvent les règles.

- [Open Finance no Banco Central](https://go.mymarketing.click/ofbr-open-finance-no-banco-central) - La page de la Banco Central avec la réglementation, les phases et les questions fréquentes. `officiel` `gratuit`
- [Open Finance Brasil](https://go.mymarketing.click/ofbr-open-finance-brasil) - Le portail de la structure de gouvernance, pour les citoyens et les participants. `officiel` `gratuit`
- [Open Insurance na Susep](https://go.mymarketing.click/ofbr-open-insurance-na-susep) - Le système d'assurance ouverte, régulé par la Susep. `officiel` `gratuit`
- [Open Insurance Brasil](https://go.mymarketing.click/ofbr-open-insurance-brasil) - Le portail de la structure de l'Open Insurance. `officiel` `gratuit`

- [OpenAPI do Open Finance](https://go.mymarketing.click/ofbr-openapi-do-open-finance) - Les fichiers OpenAPI officiels des API. `officiel` `gratuit` `code ouvert`

- [Mock API](https://go.mymarketing.click/ofbr-mock-api) - Image Docker avec des réponses d'exemple des API, pour tester sans banque. `officiel` `gratuit` `code ouvert`

## Agrégateurs et initiateurs

Ceux qui connectent les comptes à votre place. Par ordre alphabétique.

- [Belvo](https://go.mymarketing.click/ofbr-belvo) - API de données financières et de paiements via Open Finance. `API` `payant`
- [Iniciador](https://go.mymarketing.click/ofbr-iniciador) - Initiation de paiements par Open Finance. `API` `payant`
- [Klavi](https://go.mymarketing.click/ofbr-klavi) - Données Open Finance pour le crédit et l'analyse de risque. `API` `payant`
- [Pluggy](https://go.mymarketing.click/ofbr-pluggy) - API pour connecter des comptes et lire les transactions via Open Finance. `API` `payant`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de celui qui définit la norme, code ouvert quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les éléments portant l'étiquette « de l'auteur » sont réalisés par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
