## Regulasi dan tata kelola

Siapa yang mengatur dan di mana aturannya.

- [Open Finance no Banco Central](https://go.mymarketing.click/ofbr-open-finance-no-banco-central) - Halaman Banco Central dengan regulasi, tahapan, dan pertanyaan yang sering diajukan. `resmi` `gratis`
- [Open Finance Brasil](https://go.mymarketing.click/ofbr-open-finance-brasil) - Portal struktur tata kelola, untuk warga dan peserta. `resmi` `gratis`
- [Open Insurance na Susep](https://go.mymarketing.click/ofbr-open-insurance-na-susep) - Sistem asuransi terbuka, diatur oleh Susep. `resmi` `gratis`
- [Open Insurance Brasil](https://go.mymarketing.click/ofbr-open-insurance-brasil) - Portal struktur Open Insurance. `resmi` `gratis`

## Spesifikasi dan area pengembang

Yang diimplementasikan peserta.

- [Área do desenvolvedor](https://go.mymarketing.click/ofbr-area-do-desenvolvedor) - Spesifikasi API, keamanan, dan pengalaman pengguna. `resmi` `gratis` `API`
- [OpenAPI do Open Finance](https://go.mymarketing.click/ofbr-openapi-do-open-finance) - File OpenAPI resmi untuk API. `resmi` `gratis` `kode terbuka`
- [Especificações de segurança](https://go.mymarketing.click/ofbr-especificacoes-de-seguranca) - Profil keamanan FAPI dan penggunaan sertifikat dalam ekosistem. `resmi` `gratis` `kode terbuka`
- [Especificações do diretório](https://go.mymarketing.click/ofbr-especificacoes-do-diretorio) - Cara kerja direktori pusat peserta. `resmi` `gratis` `kode terbuka`
- [Mock API](https://go.mymarketing.click/ofbr-mock-api) - Image Docker dengan respons contoh API, untuk menguji tanpa bank. `resmi` `gratis` `kode terbuka`
- [Massa de dados](https://go.mymarketing.click/ofbr-massa-de-dados) - Data uji untuk API. `resmi` `gratis` `kode terbuka`
- [Aplicações de exemplo](https://go.mymarketing.click/ofbr-aplicacoes-de-exemplo) - Contoh aplikasi yang memakai API. `resmi` `gratis` `kode terbuka`

## Data terbuka ekosistem

Yang bisa dilihat siapa saja.

- [Participantes](https://go.mymarketing.click/ofbr-participantes) - Daftar publik lembaga peserta, dalam JSON. `resmi` `gratis` `API`
- [Painel do Open Finance](https://go.mymarketing.click/ofbr-painel-do-open-finance) - Angka ekosistem: panggilan API, persetujuan, dan ketersediaan. `resmi` `gratis`

## Agregator dan initiator

Yang menghubungkan rekening atas namamu. Urut abjad.

- [Belvo](https://go.mymarketing.click/ofbr-belvo) - API data keuangan dan pembayaran lewat Open Finance. `API` `berbayar`
- [Iniciador](https://go.mymarketing.click/ofbr-iniciador) - Inisiasi pembayaran lewat Open Finance. `API` `berbayar`
- [Klavi](https://go.mymarketing.click/ofbr-klavi) - Data Open Finance untuk kredit dan analisis risiko. `API` `berbayar`
- [Pluggy](https://go.mymarketing.click/ofbr-pluggy) - API untuk menghubungkan rekening dan membaca transaksi lewat Open Finance. `API` `berbayar`

## Kode terbuka

Referensi, klien, dan server MCP buatan komunitas.

- [Meu Pluggy](https://go.mymarketing.click/ofbr-meu-pluggy) - Aplikasi untuk menghubungkan rekening sendiri ke Open Finance dan mengekspor datanya. `kode terbuka` `gratis`
- [pix-automatico-reference](https://go.mymarketing.click/ofbr-pix-automatico-reference) - Implementasi referensi Pix Automático dengan alur persetujuan. `kode terbuka` `gratis`
- [open-finance-payments-reference](https://go.mymarketing.click/ofbr-open-finance-payments-reference) - Implementasi referensi dalam Java untuk initiator pembayaran. `kode terbuka` `gratis`
- [regulatorio-bcb-fundamentos](https://go.mymarketing.click/ofbr-regulatorio-bcb-fundamentos) - Panduan teknis pengantar tentang Pix, DICT, Open Finance, dan Susep. `kode terbuka` `gratis`
- [pluggy-mcp-server](https://go.mymarketing.click/ofbr-pluggy-mcp-server) - Server MCP hanya baca untuk data keuangan pribadi lewat Pluggy. `kode terbuka` `gratis`
- [banco-mcp](https://go.mymarketing.click/ofbr-banco-mcp) - Server MCP Open Finance untuk Claude dan Cursor. `kode terbuka` `gratis`
- [logos-bancos-br](https://go.mymarketing.click/ofbr-logos-bancos-br) - Logo bank, fintech, dan koperasi Brasil dalam PNG dan SVG, menurut kode COMPE. `kode terbuka` `gratis`

## Label

Setiap item menjelaskan apa itu. Label di sebelahnya membantu memilih: resmi jika berasal dari pihak yang menetapkan standar, kode terbuka jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan item lainnya.
