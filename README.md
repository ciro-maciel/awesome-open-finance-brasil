## Normas e governança

Quem regula e onde estão as regras.

- [Open Finance no Banco Central](https://go.mymarketing.click/ofbr-open-finance-no-banco-central) - A página do Banco Central com a regulamentação, as fases e as perguntas frequentes. `oficial` `grátis`
- [Open Finance Brasil](https://go.mymarketing.click/ofbr-open-finance-brasil) - O portal da estrutura de governança, para cidadãos e participantes. `oficial` `grátis`
- [Open Insurance na Susep](https://go.mymarketing.click/ofbr-open-insurance-na-susep) - O sistema de seguros aberto, regulado pela Susep. `oficial` `grátis`
- [Open Insurance Brasil](https://go.mymarketing.click/ofbr-open-insurance-brasil) - O portal da estrutura do Open Insurance. `oficial` `grátis`

## Agregadores e iniciadores

Quem conecta as contas por você. Em ordem alfabética.

- [Belvo](https://go.mymarketing.click/ofbr-belvo) - API de dados financeiros e pagamentos via Open Finance. `API` `pago`
- [Iniciador](https://go.mymarketing.click/ofbr-iniciador) - Iniciação de pagamentos por Open Finance. `API` `pago`
- [Klavi](https://go.mymarketing.click/ofbr-klavi) - Dados de Open Finance para crédito e análise de risco. `API` `pago`
- [Pluggy](https://go.mymarketing.click/ofbr-pluggy) - API para conectar contas e ler transações via Open Finance. `API` `pago`
